Introduction

disensa simulates how opinions change in a community of agents connected by a network. The same experiment can run with classic numeric rules or with LLM agents that exchange messages, each possibly driven by a different model.

Each agent holds an opinion on a single statement, a number on \([-2, 2]\) from strongly against to strongly in favour. At every step agents interact with their neighbours and update their opinion. In a classic An agent-based model (ABM) simulates a system as many individual agents, each following simple rules. The behaviour of the whole is not specified anywhere: it emerges from the interactions. the update is an equation: an agent moves towards the average opinion of its neighbours (DeGroot), or only of those close enough to its own (bounded confidence). These rules are transparent and fast, but they reduce every interaction to a number.

LLM agents replace the equation with language. Each agent reads the messages its neighbours shared, reasons about them, and replies with a new opinion, a new message and an updated memory.

Two features set disensa apart. The first is model diversity: LLM-agent simulations usually run every agent on the same model (e.g. Wang et al., 2025), so agents differ only in their prompt while the reasoning underneath is identical. Here different agents can run on different models, each bringing its own tendencies and susceptibility to persuasion. The second is individual-level inspection: every reply is saved with its reasoning and memory, so a run can be followed agent by agent, showing not only where opinions end up but why each agent moved.

Both kinds of agents share the same engine, networks and metrics, so a numeric run and an LLM run of the same setup can be compared directly.

Quick start gets a first run going and How a run works describes the loop. The sections after that cover each part of a run in turn: the network, the numeric and LLM agents, the initial opinions, the metrics, and the files a run produces.

Network topologies

Each agent is a node in the network, with its own independent state. In an LLM run, different nodes can be driven by different models (e.g. Llama, Gemma, Grok); see LLM agents for how models are assigned to nodes. A link between two nodes means those agents interact. Networks are undirected and unweighted: if \(i\) is linked to \(j\), then \(j\) is linked to \(i\), and every link counts the same. Three classic models are available to generate the network:

Random (Erdős–Rényi)

Every pair of nodes is linked with the same probability \(p\). Because links are placed purely at random, clustering is low and there are no hubs. Clustering means an agent's neighbours are also linked to each other, forming triangles: tight groups where everyone knows everyone. Hubs are single agents with far more links than average. The two are independent: a network can have one without the other.

Small-world (Watts–Strogatz)

A ring where each agent links to its \(k\) nearest neighbours, and a share \(\beta\) of the links are rewired at random. Neighbours share neighbours, so clustering is high, while the rewired links act as shortcuts that keep paths short. Tight local groups, no hubs.

Scale-free (Barabási–Albert)

A few hubs hold many links while most agents have only a few: An agent's degree \(k_i\) is its number of links, i.e. how many neighbours it has. The degree distribution \(p_k\) is the share of agents with exactly \(k\) links. follow a \(p_k \propto k^{-\gamma}\): the share of agents with \(k\) links falls off slowly, as a power of \(k\), not exponentially as in a random network. Highly connected agents stay rare but not vanishingly so, which is why hubs appear. Here \(\gamma = 3\)., with no typical value. Hubs arise from The better connected an agent is, the more likely it is to gain new links, so the rich get richer. An agent's chance of receiving a link is proportional to its degree \(k_i\).. Clustering is low; \(m\) sets the density (average degree \(2m\)).

Each model isolates one structural feature while keeping paths short, so they can be compared one feature at a time:

ClusteringHubsShort paths
RandomLowNoYes
Small-worldHighNoYes
Scale-freeLowYesYes (even shorter)
  • Random is the baseline (null model): what happens when structure plays no role, so effects seen in the other two can be attributed to their structure.
  • Small-world adds clustering: do tight local groups create echo chambers, slow down consensus or let opinion camps survive?
  • Scale-free adds hubs: do a few highly connected agents dominate, spreading opinions fast and pulling others toward them?

Describing a network

A network has \(N\) nodes (here, agents) and \(L\) links. It is stored as the adjacency matrix \(A\), with \(A_{ij} = 1\) if \(i\) and \(j\) are linked and \(0\) otherwise; for an undirected network \(A\) is symmetric.

QuantityDefinitionMeaning
Degree \(k_i\)\(k_i = \sum_j A_{ij}\)Number of neighbours of \(i\).
Average degree \(\langle k \rangle\)\(\langle k \rangle = 2L / N\)Average number of neighbours per agent. The factor 2 is there because each link counts toward the degree of both its ends.
Degree distribution \(p_k\)\(p_k = N_k / N\)Share of nodes with exactly \(k\) links. The main property separating the three models.
Distance \(d_{ij}\)links on the shortest path from \(i\) to \(j\)Averaged over all pairs it gives the average path length \(\langle d \rangle\); the largest is called the diameter.
Clustering coefficient \(C_i\)\(C_i = \dfrac{2L_i}{k_i(k_i - 1)}\)\(L_i\) is the number of links among \(i\)'s neighbours: the share of \(i\)'s neighbours that are also linked to each other. Averaged over nodes it gives \(\langle C \rangle\).

A network is connected when there is a path between every pair of nodes; otherwise it splits into components. Real networks are sparse: \(L\) is far below the maximum possible number of links, which for an undirected network is \(N(N-1)/2\), every pair linked once.

Random (Erdős–Rényi)

Every pair of the \(N\) nodes is linked independently with probability \(p\).

\[ \langle L \rangle = p\,\frac{N(N-1)}{2} \qquad \langle k \rangle = p\,(N-1) \]

Degrees. The degree distribution is binomial, and for sparse networks (\(\langle k \rangle \ll N\)) it is well approximated by a Poisson distribution, narrowly peaked around \(\langle k \rangle\). High degrees are exponentially rare, so there are no hubs: most agents have about the same number of neighbours.

\[ p_k = e^{-\langle k \rangle} \frac{\langle k \rangle^{k}}{k!} \]

Connectedness. As \(\langle k \rangle\) grows the network goes through distinct regimes: below \(\langle k \rangle = 1\) it is a set of small fragments; above \(1\) a giant component appears; around \(\langle k \rangle = \ln N\) the whole network becomes connected. The transition is sharp only for very large \(N\): with 50 agents it is gradual (see Choosing \(p\) below).

Small world. Distances are short and grow only logarithmically with size:

\[ \langle d \rangle \approx \frac{\ln N}{\ln \langle k \rangle} \]

Clustering. Two neighbours of a node are linked with the same probability \(p\) as any other pair, so clustering is low, independent of degree, and shrinks as the network grows:

\[ \langle C \rangle = p = \frac{\langle k \rangle}{N-1} \approx \frac{\langle k \rangle}{N} \]

Real networks have far more clustering and far broader degree distributions than this model predicts. It is used as the null model: what a network looks like when links are placed purely at random.

Choosing \(p\). The network becomes connected around \(\langle k \rangle = \ln N\). With 50 agents \(\ln 50 \approx 3.9\), so \(p \approx 3.9 / 49 \approx 0.08\). That is the threshold, not a safe value: at \(p = 0.08\) only about 40% of draws are connected, and the rest get redrawn (see below). With \(p \approx 0.12\) (\(\langle k \rangle \approx 6\)), over 90% of draws are connected.

Small-world (Watts–Strogatz)

Real networks are both clustered (your neighbours know each other) and The small-world property: the average distance between two nodes grows only like \(\ln N\), so even in a huge network anyone is a few steps from anyone (“six degrees of separation”). Random networks already have it: in \(d\) steps a node reaches about \(\langle k \rangle^d\) others, so a few steps cover the whole network. Network Science, ch. 3 → (short paths between anyone). A Ring, \(k = 4\)Square gridA regular lattice places nodes on a regular pattern and links each only to its nearest neighbours, so every node looks the same. It has high clustering but long paths: distances grow like \(N\) on a ring or \(\sqrt{N}\) on a grid, not \(\ln N\). has the first but not the second; a random network has the second but not the first. The Watts–Strogatz model interpolates between the two:

  1. Start from a ring where each node is linked to its \(k\) nearest neighbours.
  2. Rewire each link with probability \(\beta\), moving one end to a randomly chosen node.
  • \(\beta = 0\): the ring lattice. High clustering, long paths.
  • \(\beta = 1\): essentially a random network. Low clustering, short paths.
  • Small \(\beta\) (for example \(0.01\)–\(0.1\)): a few rewired links act as shortcuts across the ring, so \(\langle d \rangle\) drops sharply, while almost all local triangles survive and clustering stays high. This is the small-world regime.

Every node starts with degree \(k\) and rewiring moves only one end of a link, so degrees stay close to \(k\): \(\langle k \rangle = k\) and there are no hubs.

Clustering. On the ring, \(C(0) = \dfrac{3(k-2)}{4(k-1)}\): \(0.5\) for \(k = 4\), \(0.6\) for \(k = 6\), and \(0\) for \(k = 2\), where an agent's two neighbours are never linked. A triangle survives only if none of its three links is rewired, so clustering falls as

\[ C(\beta) \approx C(0)\,(1-\beta)^3 \]

At \(\beta = 0.1\) about 73% of the ring's clustering is left; past \(\beta \approx 0.2\) less than half is, and the network looks increasingly random.

Scale-free (Barabási–Albert)

This topology introduces the scale-free property: as in many real networks, the degree distribution follows a power law rather than a Poisson distribution:

\[ p_k \sim k^{-\gamma} \]

A power law decays slowly, so very high degrees are rare but not negligible: the network has hubs, nodes with far more links than average. \(\langle k \rangle\) is then a poor description of a typical node.

The degree exponent. \(\gamma\) is not fixed by the definition, but it The shares \(p_k = C\,k^{-\gamma}\) must add up to \(1\), so the sum \(\sum_{k \ge 1} k^{-\gamma}\) has to be finite. It is only for \(\gamma > 1\). At \(\gamma = 1\) it is the harmonic series \(1 + \tfrac12 + \tfrac13 + \dots\), which grows forever, and smaller \(\gamma\) only makes it grow faster. With an infinite sum, no constant \(C\) can make the shares add up to \(1\). for \(p_k\) to be a valid distribution, and its value decides how the network behaves. Most real networks have \(2 < \gamma < 3\); Barabási–Albert always gives \(\gamma = 3\).

  • \(1 < \gamma < 2\): the largest hub would need more links than there are nodes, so large networks without repeated links cannot have it.
  • \(2 < \gamma < 3\): hubs are large enough to dominate. Distances are tiny, \(\langle d \rangle \sim \ln \ln N\): an Hubs act as shortcuts: most paths pass through one, and hubs are linked to each other, so distances grow like \(\ln \ln N\), even more slowly than the \(\ln N\) of a random network. With a million nodes, \(\ln N \approx 14\) but \(\ln \ln N \approx 2.6\). Network Science, ch. 4 →.
  • \(\gamma = 3\): the boundary case, \(\langle d \rangle \sim \ln N / \ln \ln N\), still shorter than in a random network.
  • \(\gamma > 3\): hubs are too small to matter and the network behaves much like a random one, \(\langle d \rangle \sim \ln N\).

Barabási–Albert produces a power-law degree distribution with two mechanisms:

  1. Growth. Start from a few nodes and add one node at a time, each with \(m\) links.
  2. Preferential attachment. Each new link goes to existing node \(i\) with probability proportional to its degree:
\[ \Pi(k_i) = \frac{k_i}{\sum_j k_j} \]

Well-connected nodes get more new links, so they become better connected (“the rich get richer”). A node that arrived at time \(t_i\) has, at time \(t\),

\[ \langle k_i(t) \rangle \approx m \left( \frac{t}{t_i} \right)^{1/2} \]

so the oldest nodes become the hubs (first-mover advantage). The resulting degree distribution is a power law with \(\gamma = 3\), whatever the value of \(m\):

\[ p_k \approx 2m(m+1)\,k^{-3} \qquad \langle k \rangle \approx 2m \]

Both mechanisms are needed. Growth without preferential attachment gives an exponential degree distribution (no hubs). Preferential attachment without growth gives no stationary power law: the network eventually becomes fully connected.

Clustering is low, \(\langle C \rangle \sim (\ln N)^2 / N\). That is higher than in a random network of the same size, but it still vanishes as \(N\) grows.

In disensa

Networks are built with NetworkX (network.py). Every network is seeded, so the same seed gives the same network, and always connected: a disconnected draw is redrawn with a new seed derived from the original, up to 100 times. This matters for two reasons. Opinions only travel along links, so separate parts of a network would never influence each other and would evolve as independent simulations. And only Erdős–Rényi can split (Barabási–Albert is connected by construction, and Watts–Strogatz is built connected), so allowing it would add a difference between topologies that has nothing to do with their structure. All topologies take n, the number of agents (default 50).

  • Scale-free: \(m = 3\) (5.64 links per agent, see above)

Numeric algorithms

Numeric algorithms are the classic way to model how agents (the nodes of the network) update their opinions. Where an LLM agent changes its opinion by prompting a language model, a numeric agent applies an algebraic equation that computes its new opinion deterministically from its own opinion and those of its neighbours. disensa has three algorithms, all in dynamics/numeric.py: DeGroot is plain averaging, and the other two each add one mechanism to it, a similarity filter (bounded confidence) or stubbornness (Friedkin–Johnsen). Like LLM agents, every agent reads the opinions of step \(t-1\) and all updates apply together, using the adjacency matrix \(A\) from Describing a network. All three belong to the family of Assimilative influence: when an agent updates, its opinion moves towards the opinions of the neighbours it listens to, never away from them. Models where opinions can also be pushed apart (repulsion) are a separate family, not implemented here. See Flache et al. (2017), §2. models.

DeGroot (averaging)

At each step, every agent replaces its opinion with the average of its own opinion and those of its neighbours \(N(i)\) at the previous step. Every opinion in the average counts the same: an agent with \(k_i\) neighbours averages \(k_i + 1\) values, its own included.

\[ x_i(t) = \frac{1}{k_i + 1} \sum_{j \in N(i) \cup \{i\}} x_j(t-1) \]

Matrix form. The same update can be written for all agents at once. Put every opinion in a column vector \(x(t) = (x_1(t), \dots, x_N(t))^\top\) and every weight in an \(N \times N\) matrix \(W\), where \(W_{ij}\) is how much agent \(i\) listens to agent \(j\) (in disensa, the same for itself and each of its neighbours). Then the whole step is one multiplication:

\[ x(t) = W\,x(t-1) \]

Element \(i\) of the resulting vector is \(\sum_j W_{ij}\, x_j(t-1)\), agent \(i\)’s new opinion: the same update as above. In disensa, \(W_{ij} = 1/(k_i + 1)\) if \(j\) is \(i\) itself or one of its neighbours, and \(0\) otherwise. With the adjacency matrix \(A\) and the identity matrix \(I\) (which links each agent to itself), that is

\[ W_{ij} = \frac{A_{ij} + I_{ij}}{k_i + 1} \]

Every entry of \(W\) is \(\ge 0\) and every row sums to \(1\): \(W\) is Row-stochastic matrix: a square matrix whose entries are all \(\ge 0\) and whose rows each sum to \(1\), \(\sum_j W_{ij} = 1\) for every \(i\). Each row is a set of weights, so multiplying a vector by it turns every entry into a weighted average of the vector’s entries.. That is what makes each new opinion a weighted average of the old ones. DeGroot’s general model allows any row-stochastic \(W\), so agents can weigh each other differently; disensa uses the equal weights above.

Example: one step on a path of three agents

Three agents on a path \(1 - 2 - 3\): agent 2 has two neighbours, agents 1 and 3 have one each. They start from \(x(0) = (-2,\ -1,\ 1.5)^\top\).

Build \(W\) from the network. The adjacency matrix \(A\) marks who is linked to whom; adding \(I\) puts a \(1\) on the diagonal, so each agent also counts itself:

\[ A + I = \begin{pmatrix} 0 & 1 & 0 \\ 1 & 0 & 1 \\ 0 & 1 & 0 \end{pmatrix} + \begin{pmatrix} 1 & 0 & 0 \\ 0 & 1 & 0 \\ 0 & 0 & 1 \end{pmatrix} = \begin{pmatrix} 1 & 1 & 0 \\ 1 & 1 & 1 \\ 0 & 1 & 1 \end{pmatrix} \]

Row \(i\) now has \(k_i + 1\) ones: one for each opinion agent \(i\) averages. Dividing each row by that count makes the row sum to \(1\):

\[ k + 1 = \begin{pmatrix} 2 \\ 3 \\ 2 \end{pmatrix} \quad\Longrightarrow\quad W = \begin{pmatrix} \frac12 & \frac12 & 0 \\[6pt] \frac13 & \frac13 & \frac13 \\[6pt] 0 & \frac12 & \frac12 \end{pmatrix} \]

One step is one multiplication:

\[ x(1) = W\,x(0) = \begin{pmatrix} \frac12 & \frac12 & 0 \\[6pt] \frac13 & \frac13 & \frac13 \\[6pt] 0 & \frac12 & \frac12 \end{pmatrix} \begin{pmatrix} -2 \\[6pt] -1 \\[6pt] 1.5 \end{pmatrix} = \begin{pmatrix} \tfrac{-2-1}{2} \\[6pt] \tfrac{-2-1+1.5}{3} \\[6pt] \tfrac{-1+1.5}{2} \end{pmatrix} = \begin{pmatrix} -1.5 \\[6pt] -0.5 \\[6pt] 0.25 \end{pmatrix} \]

Every agent moves towards its neighbours. Agent 2, in the middle, hears both sides; agents 1 and 3 only hear agent 2. The gap between the most extreme opinions halves, from \(3.5\) to \(1.75\), and keeps halving at every step as the three opinions approach the same value.

Where it goes. On a connected network, averaging converges to consensus: as the steps go on, all opinions approach the same value (DeGroot, 1974; Flache et al., 2017, §2). They get arbitrarily close but, in general, never become exactly equal: the gap between the highest and lowest opinion shrinks by a roughly constant factor every step (in the example above it halves). disensa networks are always connected, so a long enough DeGroot run always gets close to consensus. Because each update is an average, opinions also never leave the range of the initial ones.

The consensus value. The value they approach, \(x^\ast\), is a weighted average of the initial opinions \(x_i(0)\) of the agents \(i = 1, \dots, N\), with weights proportional to \(k_i + 1\):

\[ x^\ast = \sum_i w_i\, x_i(0), \qquad w_i = \frac{k_i + 1}{\sum_j (k_j + 1)} \]

The weights sum to \(1\). Well-connected agents are listened to by more agents, so they pull the consensus towards their own starting opinion; in a scale-free network, hubs get a visibly larger say. The reason is that the sum of opinions weighted by \(k_i + 1\) stays the same at every step, so at consensus it still equals its starting value. In the example, \(x^\ast = (2 \cdot (-2) + 3 \cdot (-1) + 2 \cdot 1.5) / 7 \approx -0.57\), not the plain average \(-0.5\): agent 2 has the most neighbours, so its opinion counts more.

That is also the model's limit. It cannot produce polarization or echo chambers, only consensus, which makes it the reference point: anything else a run shows comes from what the other rules add.

Bounded confidence

Agents only listen to neighbours whose opinion is already close to their own: within a confidence bound \(\varepsilon\). Neighbours further away are ignored. For agent \(i\), the neighbours it listens to, together with itself, form its Agent \(i\) itself plus the neighbours \(j\) with \(|x_i - x_j| \le \varepsilon\) at step \(t-1\). It changes every step as opinions move, so two agents can stop listening to each other once they drift apart, and start again if they come close. \(C_i(t-1) = \{\, j \in N(i) \cup \{i\} : |x_i(t-1) - x_j(t-1)| \le \varepsilon \,\}\), and the agent moves towards the average of that set, but only part of the way: it covers a fraction \(\mu\) of the distance between its opinion and that average. With \(\mu = 1\) it jumps straight to the average; with \(\mu = 0.5\) it goes halfway.

\[ x_i(t) = x_i(t-1) + \mu \left( \frac{1}{|C_i|} \sum_{j \in C_i} x_j(t-1) \;-\; x_i(t-1) \right) \]

If no neighbour is within \(\varepsilon\), the set holds only the agent itself, so it keeps its opinion.

  • \(\varepsilon\) (epsilon): how open-minded agents are. It decides the outcome.
  • \(\mu\) (mu, \(0 < \mu \le 1\)): how far an agent moves per step; \(\mu = 1\) is plain Hegselmann–Krause. It mainly affects the speed.

Two classic versions. Bounded confidence has two standard forms; disensa uses a variant that combines them:

ModelWho updatesUpdate
Deffuant et al. (2000)One random pair at a timeEach moves \(\mu\) towards the other, if within \(\varepsilon\).
Hegselmann–Krause (2002)Everyone at onceEach takes the plain average of all agents within \(\varepsilon\), itself included (\(\mu = 1\)), originally with everyone able to see everyone.
Inertial Hegselmann–Krause (Chazelle & Wang, 2017), used by disensaEveryone at onceAverages all agents within \(\varepsilon\), itself included, like Hegselmann–Krause, but moves only \(\mu\) of the way towards that average, like Deffuant. The original has no network (anyone within \(\varepsilon\) counts); in disensa only linked agents count.

Where it goes. If \(\varepsilon\) is large, everyone is eventually linked by chains of agents who listen to each other and opinions converge to consensus, as with DeGroot. If \(\varepsilon\) is small, the population splits into separate opinion clusters that no longer listen to each other; the smaller \(\varepsilon\), the more and smaller the clusters (Flache et al., 2017, §2). Hegselmann and Krause (2002, §4.1) describe three phases as \(\varepsilon\) grows:

  • Plurality: many opinions survive.
  • Polarization: two camps.
  • Consensus: everyone converges to one opinion.

On a network the bound is not the only obstacle: an agent can only be pulled by its own neighbours, so clusters also form where the network itself keeps groups apart.

As with DeGroot, every update is an average (for \(\mu \le 1\)), so opinions stay within the initial range: the model can split a population into camps, but not make it more extreme than its initial extremists (Flache et al., 2017, §2).

Large \(\varepsilon\). Opinions are at most \(4\) apart, so with \(\varepsilon \ge 4\) every neighbour is always in the confidence set; with \(\mu = 1\) the rule is then exactly DeGroot.

Friedkin–Johnsen (stubbornness)

Agents average with their neighbours, but never fully let go of where they started. Each agent keeps its initial opinion \(s_i = x_i(0)\) as its The innate opinion \(s_i\) is the view an agent holds on its own, before any influence; it never changes. What changes is the opinion it expresses, \(x_i(t)\), which mixes \(s_i\) with what its neighbours say. Friedkin and Johnsen call the pull of \(s_i\) the agent's prejudice or stubbornness. and mixes it with its neighbours' current opinions, as in Chitra & Musco (2020, eq. 1):

\[ x_i(t) = \frac{\lambda\, s_i + \sum_{j \in N(i)} x_j(t-1)}{\lambda + k_i} \]

The sum runs over agent \(i\)’s neighbours \(N(i)\), and \(k_i\) is its degree (how many neighbours it has).

\(\lambda\) (stubbornness) is how much the innate opinion weighs compared with one neighbour. Chitra & Musco use \(\lambda = 1\): the innate opinion counts as one extra neighbour. Since the sum over \(k_i\) neighbours is \(k_i\) times their average \(\bar{x}_{N(i)}(t-1)\), the update is a weighted average of the innate opinion and the neighbours’ average:

\[ x_i(t) = \frac{\lambda}{\lambda + k_i}\, s_i \;+\; \frac{k_i}{\lambda + k_i}\, \bar{x}_{N(i)}(t-1) \]

The more neighbours an agent has, the less weight its innate opinion gets, so well-connected agents are pulled harder by the group. In the original model (Friedkin & Johnsen, 1990) the weight on each agent’s innate opinion is a separate parameter, set freely per agent; here it follows from the degree.

Where it goes. Not to a common consensus. Every agent keeps being pulled back towards its own innate opinion \(s_i\), so each agent approaches its own equilibrium \(x_i^\ast\): the opinion at which the pull of its innate opinion and the pull of its neighbours’ average balance, so that it no longer changes from one step to the next. Neighbours end up closer than they started, but disagreement never disappears: large \(\lambda\) keeps agents near their innate opinions, small \(\lambda\) brings them close to consensus. Opinions stay within the initial range, as with the other two rules.

Computing the equilibrium. The equilibrium can be computed directly, without running the simulation, using the Graph Laplacian: the matrix \(L = D - A\), with each agent’s degree on the diagonal, \(-1\) for each link and \(0\) elsewhere, so every row sums to \(0\). It measures differences across links: \(L\,x\) is \(0\) for every agent exactly when all neighbours agree. \(L = D - A\). Here \(A\) is the adjacency matrix and \(D\) is the degree matrix: a diagonal matrix with each agent’s degree \(k_i\) on the diagonal and zeros elsewhere. Multiplied by the opinion vector \(x\), \(L\) gives each agent’s total difference from its neighbours: positive if it sits above them, negative if below. For agent \(i\), that is element \(i\) of the vector \(L\,x\), i.e. row \(i\) of \(L\) times \(x\):

\[ (L\,x)_i = k_i\, x_i - \sum_{j \in N(i)} x_j = \sum_{j \in N(i)} (x_i - x_j) \]

Row \(i\) of \(L\) has \(k_i\) on the diagonal, \(-1\) for each neighbour and \(0\) for everyone else, so non-neighbours drop out. The result is \(0\) when the agent sits exactly at its neighbours’ average.

At equilibrium opinions stop changing, so \(x_i(t) = x_i(t-1) = x_i^\ast\). Putting this into the update and rearranging gives, for every agent,

\[ \lambda\,(x_i^\ast - s_i) + (L\,x^\ast)_i = 0 \]

its distance from its innate opinion balances its distance from its neighbours. For all agents at once this is one linear system, solved for \(x^\ast\):

\[ (\lambda I + L)\, x^\ast = \lambda\, s \qquad\Longrightarrow\qquad x^\ast = \lambda\, (\lambda I + L)^{-1}\, s \]
Derivation, step by step
  1. At equilibrium nothing changes, \(x_i(t) = x_i(t-1) = x_i^\ast\), so every opinion in the update becomes \(x^\ast\):
    \[ x_i^\ast = \frac{\lambda\, s_i + \sum_{j \in N(i)} x_j^\ast}{\lambda + k_i} \]
  2. Multiply both sides by \(\lambda + k_i\):
    \[ \lambda\, x_i^\ast + k_i\, x_i^\ast = \lambda\, s_i + \sum_{j \in N(i)} x_j^\ast \]
  3. Move everything to the left and group. The first term is the agent’s distance from its innate opinion, the second its distance from its neighbours, and they cancel:
    \[ \underbrace{\lambda\,(x_i^\ast - s_i)}_{\text{from innate opinion}} \;+\; \underbrace{k_i\, x_i^\ast - \sum_{j \in N(i)} x_j^\ast}_{(L\,x^\ast)_i\text{, from neighbours}} = 0 \]

Stacking the equations for all agents gives \(\lambda\,(x^\ast - s) + L\,x^\ast = 0\), and since \(\lambda\, x^\ast = \lambda I\, x^\ast\) this is \((\lambda I + L)\, x^\ast = \lambda\, s\). \(\lambda I + L\) can be inverted because \(\lambda > 0\).

Example: the equilibrium on a path of three agents

The same path \(1 - 2 - 3\) as in the DeGroot example, with innate opinions \(s = x(0) = (-2,\ -1,\ 1.5)^\top\) and \(\lambda = 1\).

Build the Laplacian from the degrees and the links:

\[ L = D - A = \begin{pmatrix} 1 & 0 & 0 \\ 0 & 2 & 0 \\ 0 & 0 & 1 \end{pmatrix} - \begin{pmatrix} 0 & 1 & 0 \\ 1 & 0 & 1 \\ 0 & 1 & 0 \end{pmatrix} = \begin{pmatrix} 1 & -1 & 0 \\ -1 & 2 & -1 \\ 0 & -1 & 1 \end{pmatrix} \]

At the start, \(L\,s\) shows how far each agent sits from its neighbours: agent 1 is \(1\) below agent 2, agent 3 is \(2.5\) above agent 2, and agent 2 is pulled both ways:

\[ L\,s = \begin{pmatrix} 1 & -1 & 0 \\ -1 & 2 & -1 \\ 0 & -1 & 1 \end{pmatrix} \begin{pmatrix} -2 \\ -1 \\ 1.5 \end{pmatrix} = \begin{pmatrix} -1 \\ -1.5 \\ 2.5 \end{pmatrix} \]

The equilibrium solves \((\lambda I + L)\, x^\ast = \lambda\, s\). With \(\lambda = 1\), \(\lambda I + L\) adds \(1\) to each diagonal entry of \(L\), and \(\lambda\, s = s\):

\[ \lambda I + L = 1 \cdot \begin{pmatrix} 1 & 0 & 0 \\ 0 & 1 & 0 \\ 0 & 0 & 1 \end{pmatrix} + \begin{pmatrix} 1 & -1 & 0 \\ -1 & 2 & -1 \\ 0 & -1 & 1 \end{pmatrix} = \begin{pmatrix} 2 & -1 & 0 \\ -1 & 3 & -1 \\ 0 & -1 & 2 \end{pmatrix} \]
\[ \lambda\, s = 1 \cdot \begin{pmatrix} -2 \\ -1 \\ 1.5 \end{pmatrix} = \begin{pmatrix} -2 \\ -1 \\ 1.5 \end{pmatrix} \]

Solving:

\[ \begin{pmatrix} 2 & -1 & 0 \\ -1 & 3 & -1 \\ 0 & -1 & 2 \end{pmatrix}\, x^\ast = \begin{pmatrix} -2 \\ -1 \\ 1.5 \end{pmatrix} \qquad\Longrightarrow\qquad x^\ast = \begin{pmatrix} -1.3125 \\ -0.625 \\ 0.4375 \end{pmatrix} \]

Each agent settles at its own value, between its innate opinion and its neighbours. The gap between the most extreme opinions shrinks from \(3.5\) to \(1.75\) and stays there; DeGroot, on the same path, brings all three to \(-0.57\). Agent 1, for example, balances a pull of \(0.69\) back towards its innate \(-2\) against a pull of \(0.69\) towards agent 2.
