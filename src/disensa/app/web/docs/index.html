Network topologies

Each agent is a node in the network, with its own independent state. In an LLM run, different nodes can be driven by different models (e.g. Llama, Gemma, Grok); see LLM agents for how models are assigned to nodes. A link between two nodes means those agents interact. Networks are undirected and unweighted: if \(i\) is linked to \(j\), then \(j\) is linked to \(i\), and every link counts the same. Three classic models are available to generate the network:

Random (Erdős–Rényi)

Every pair of nodes is linked with the same probability \(p\). Because links are placed purely at random, clustering is low and there are no hubs. Clustering means an agent's neighbours are also linked to each other, forming triangles: tight groups where everyone knows everyone. Hubs are single agents with far more links than average. The two are independent: a network can have one without the other.

Small-world (Watts–Strogatz)

A ring where each agent links to its \(k\) nearest neighbours, and a share \(\beta\) of the links are rewired at random. Neighbours share neighbours, so clustering is high, while the rewired links act as shortcuts that keep paths short. Tight local groups, no hubs.

Scale-free (Barabási–Albert)

A few hubs hold many links while most agents have only a few: An agent's degree \(k_i\) is its number of links, i.e. how many neighbours it has. The degree distribution \(p_k\) is the share of agents with exactly \(k\) links. follow a \(p_k \propto k^{-\gamma}\): the share of agents with \(k\) links falls off slowly, as a power of \(k\), not exponentially as in a random network. Highly connected agents stay rare but not vanishingly so, which is why hubs appear. Here \(\gamma = 3\)., with no typical value. Hubs arise from The better connected an agent is, the more likely it is to gain new links, so the rich get richer. An agent's chance of receiving a link is proportional to its degree \(k_i\).. Clustering is low; \(m\) sets the density (average degree \(2m\)).

Each model isolates one structural feature while keeping paths short, so they can be compared one feature at a time:

ClusteringHubsShort paths
RandomLowNoYes
Small-worldHighNoYes
Scale-freeLowYesYes (even shorter)
  • Random is the baseline (null model): what happens when structure plays no role, so effects seen in the other two can be attributed to their structure.
  • Small-world adds clustering: do tight local groups create echo chambers, slow down consensus or let opinion camps survive?
  • Scale-free adds hubs: do a few highly connected agents dominate, spreading opinions fast and pulling others toward them?

Describing a network

A network has \(N\) nodes (here, agents) and \(L\) links. It is stored as the adjacency matrix \(A\), with \(A_{ij} = 1\) if \(i\) and \(j\) are linked and \(0\) otherwise; for an undirected network \(A\) is symmetric.

QuantityDefinitionMeaning
Degree \(k_i\)\(k_i = \sum_j A_{ij}\)Number of neighbours of \(i\).
Average degree \(\langle k \rangle\)\(\langle k \rangle = 2L / N\)Average number of neighbours per agent. The factor 2 is there because each link counts toward the degree of both its ends.
Degree distribution \(p_k\)\(p_k = N_k / N\)Share of nodes with exactly \(k\) links. The main property separating the three models.
Distance \(d_{ij}\)links on the shortest path from \(i\) to \(j\)Averaged over all pairs it gives the average path length \(\langle d \rangle\); the largest is called the diameter.
Clustering coefficient \(C_i\)\(C_i = \dfrac{2L_i}{k_i(k_i - 1)}\)\(L_i\) is the number of links among \(i\)'s neighbours: the share of \(i\)'s neighbours that are also linked to each other. Averaged over nodes it gives \(\langle C \rangle\).

A network is connected when there is a path between every pair of nodes; otherwise it splits into components. Real networks are sparse: \(L\) is far below the maximum possible number of links, which for an undirected network is \(N(N-1)/2\), every pair linked once.

Random (Erdős–Rényi)

Every pair of the \(N\) nodes is linked independently with probability \(p\).

\[ \langle L \rangle = p\,\frac{N(N-1)}{2} \qquad \langle k \rangle = p\,(N-1) \]

Degrees. The degree distribution is binomial, and for sparse networks (\(\langle k \rangle \ll N\)) it is well approximated by a Poisson distribution, narrowly peaked around \(\langle k \rangle\). High degrees are exponentially rare, so there are no hubs: most agents have about the same number of neighbours.

\[ p_k = e^{-\langle k \rangle} \frac{\langle k \rangle^{k}}{k!} \]

Connectedness. As \(\langle k \rangle\) grows the network goes through distinct regimes: below \(\langle k \rangle = 1\) it is a set of small fragments; above \(1\) a giant component appears; around \(\langle k \rangle = \ln N\) the whole network becomes connected. The transition is sharp only for very large \(N\): with 50 agents it is gradual (see Choosing \(p\) below).

Small world. Distances are short and grow only logarithmically with size:

\[ \langle d \rangle \approx \frac{\ln N}{\ln \langle k \rangle} \]

Clustering. Two neighbours of a node are linked with the same probability \(p\) as any other pair, so clustering is low, independent of degree, and shrinks as the network grows:

\[ \langle C \rangle = p = \frac{\langle k \rangle}{N-1} \approx \frac{\langle k \rangle}{N} \]

Real networks have far more clustering and far broader degree distributions than this model predicts. It is used as the null model: what a network looks like when links are placed purely at random.

Choosing \(p\). The network becomes connected around \(\langle k \rangle = \ln N\). With 50 agents \(\ln 50 \approx 3.9\), so \(p \approx 3.9 / 49 \approx 0.08\). That is the threshold, not a safe value: at \(p = 0.08\) only about 40% of draws are connected, and the rest get redrawn (see below). With \(p \approx 0.12\) (\(\langle k \rangle \approx 6\)), over 90% of draws are connected.

Small-world (Watts–Strogatz)

Real networks are both clustered (your neighbours know each other) and The small-world property: the average distance between two nodes grows only like \(\ln N\), so even in a huge network anyone is a few steps from anyone (“six degrees of separation”). Random networks already have it: in \(d\) steps a node reaches about \(\langle k \rangle^d\) others, so a few steps cover the whole network. Network Science, ch. 3 → (short paths between anyone). A Ring, \(k = 4\)Square gridA regular lattice places nodes on a regular pattern and links each only to its nearest neighbours, so every node looks the same. It has high clustering but long paths: distances grow like \(N\) on a ring or \(\sqrt{N}\) on a grid, not \(\ln N\). has the first but not the second; a random network has the second but not the first. The Watts–Strogatz model interpolates between the two:

  1. Start from a ring where each node is linked to its \(k\) nearest neighbours.
  2. Rewire each link with probability \(\beta\), moving one end to a randomly chosen node.
  • \(\beta = 0\): the ring lattice. High clustering, long paths.
  • \(\beta = 1\): essentially a random network. Low clustering, short paths.
  • Small \(\beta\) (for example \(0.01\)–\(0.1\)): a few rewired links act as shortcuts across the ring, so \(\langle d \rangle\) drops sharply, while almost all local triangles survive and clustering stays high. This is the small-world regime.

Every node starts with degree \(k\) and rewiring moves only one end of a link, so degrees stay close to \(k\): \(\langle k \rangle = k\) and there are no hubs.

Clustering. On the ring, \(C(0) = \dfrac{3(k-2)}{4(k-1)}\): \(0.5\) for \(k = 4\), \(0.6\) for \(k = 6\), and \(0\) for \(k = 2\), where an agent's two neighbours are never linked. A triangle survives only if none of its three links is rewired, so clustering falls as

\[ C(\beta) \approx C(0)\,(1-\beta)^3 \]

At \(\beta = 0.1\) about 73% of the ring's clustering is left; past \(\beta \approx 0.2\) less than half is, and the network looks increasingly random.

Scale-free (Barabási–Albert)

This topology introduces the scale-free property: as in many real networks, the degree distribution follows a power law rather than a Poisson distribution:

\[ p_k \sim k^{-\gamma} \]

A power law decays slowly, so very high degrees are rare but not negligible: the network has hubs, nodes with far more links than average. \(\langle k \rangle\) is then a poor description of a typical node.

The degree exponent. \(\gamma\) is not fixed by the definition, but it The shares \(p_k = C\,k^{-\gamma}\) must add up to \(1\), so the sum \(\sum_{k \ge 1} k^{-\gamma}\) has to be finite. It is only for \(\gamma > 1\). At \(\gamma = 1\) it is the harmonic series \(1 + \tfrac12 + \tfrac13 + \dots\), which grows forever, and smaller \(\gamma\) only makes it grow faster. With an infinite sum, no constant \(C\) can make the shares add up to \(1\). for \(p_k\) to be a valid distribution, and its value decides how the network behaves. Most real networks have \(2 < \gamma < 3\); Barabási–Albert always gives \(\gamma = 3\).

  • \(1 < \gamma < 2\): the largest hub would need more links than there are nodes, so large networks without repeated links cannot have it.
  • \(2 < \gamma < 3\): hubs are large enough to dominate. Distances are tiny, \(\langle d \rangle \sim \ln \ln N\): an Hubs act as shortcuts: most paths pass through one, and hubs are linked to each other, so distances grow like \(\ln \ln N\), even more slowly than the \(\ln N\) of a random network. With a million nodes, \(\ln N \approx 14\) but \(\ln \ln N \approx 2.6\). Network Science, ch. 4 →.
  • \(\gamma = 3\): the boundary case, \(\langle d \rangle \sim \ln N / \ln \ln N\), still shorter than in a random network.
  • \(\gamma > 3\): hubs are too small to matter and the network behaves much like a random one, \(\langle d \rangle \sim \ln N\).

Barabási–Albert produces a power-law degree distribution with two mechanisms:

  1. Growth. Start from a few nodes and add one node at a time, each with \(m\) links.
  2. Preferential attachment. Each new link goes to existing node \(i\) with probability proportional to its degree:
\[ \Pi(k_i) = \frac{k_i}{\sum_j k_j} \]

Well-connected nodes get more new links, so they become better connected (“the rich get richer”). A node that arrived at time \(t_i\) has, at time \(t\),

\[ \langle k_i(t) \rangle \approx m \left( \frac{t}{t_i} \right)^{1/2} \]

so the oldest nodes become the hubs (first-mover advantage). The resulting degree distribution is a power law with \(\gamma = 3\), whatever the value of \(m\):

\[ p_k \approx 2m(m+1)\,k^{-3} \qquad \langle k \rangle \approx 2m \]

Both mechanisms are needed. Growth without preferential attachment gives an exponential degree distribution (no hubs). Preferential attachment without growth gives no stationary power law: the network eventually becomes fully connected.

Clustering is low, \(\langle C \rangle \sim (\ln N)^2 / N\). That is higher than in a random network of the same size, but it still vanishes as \(N\) grows.

In disensa

Networks are built with NetworkX (network.py). Every network is seeded, so the same seed gives the same network, and always connected: a disconnected draw is redrawn with a new seed derived from the original, up to 100 times. This matters for two reasons. Opinions only travel along links, so separate parts of a network would never influence each other and would evolve as independent simulations. And only Erdős–Rényi can split (Barabási–Albert is connected by construction, and Watts–Strogatz is built connected), so allowing it would add a difference between topologies that has nothing to do with their structure. All topologies take n, the number of agents (default 50).

TopologyConfig parametersTypical values (50 agents)
erdos_renyip: link probability \(p \in [0, 1]\)\(p = 0.12\text{–}0.15\)  \((\langle k \rangle \approx 6\text{–}7)\)
watts_strogatzk: neighbours on the ring (even); beta: rewiring probability \(\beta \in [0, 1]\)\(k = 4\text{–}6\), \(\beta = 0.1\)
barabasi_albertm: links per new agent\(m = 2\text{–}3\)  \((\langle k \rangle \approx 3.8\text{–}5.6)\)
Why Barabási–Albert gives slightly fewer links. NetworkX starts the network from a small star of \(m + 1\) agents (NetworkX docs). Every agent added afterwards brings \(m\) links, but the starting agents have fewer. For \(m = 3\) and 50 agents the average is \(5.64\) links per agent instead of \(6\).
Comparing topologies. To see the effect of structure alone, every topology should have the same number of agents and about the same number of links per agent; otherwise one network is simply denser than another. For 50 agents and about 6 links per agent:
  • Random: \(p = 0.12\)
  • Small-world: \(k = 6\)
  • Scale-free: \(m = 3\) (5.64 links per agent, see above)
